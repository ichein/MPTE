my personal text editor 
this proyect is for fun
works whit a personal extension to ".mdox"

About ".mdox": MDOX is its own document (I do not know if this extension exists or is commonly used).<br> Without any specific objective, only being a text editor tailor-made for me, without depending on external ones such as Google Docs or Microsoft Word

the default path where documents are saved is "MPTE/documents" you can change the path in "MPTE/config/general.json" <br>

Things you can set up in genral.json <br> 
    --reading path and saving type document .mdox
